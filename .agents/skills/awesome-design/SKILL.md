# Awesome Design (DESIGN.md Library)

A comprehensive library of curated `DESIGN.md` specifications modeling the world's most admired web and product interfaces.

## When to Use

Use this skill when redesigning, styling, or creating UI components that need to follow a proven, high-end brand aesthetic. Rather than guessing design tokens, spacing, and font hierarchies, pull the exact `DESIGN.md` profile from `design-md/<brand>/DESIGN.md`.

## Available Brand Systems (in `design-md/`)

- **Developer & Tech:** `linear.app`, `stripe`, `vercel`, `supabase`, `raycast`, `warp`, `resend`, `posthog`, `sentry`, `replicate`, `mintlify`, `cursor`
- **AI & Frontier:** `claude`, `mistral.ai`, `together.ai`, `runwayml`, `ollama`, `x.ai`, `lovable`
- **Consumer & Enterprise:** `apple`, `notion`, `figma`, `framer`, `spotify`, `slack`, `airbnb`, `shopify`, `uber`
- **Automotive & Premium:** `tesla`, `bugatti`, `ferrari`, `bmw-m`, `spacex`
- **Editorial & Media:** `wired`, `theverge`

## How to Apply a Brand's Design System

1. Locate the brand's specification in `./design-md/<brand>/DESIGN.md`.
2. Extract the 9 core sections:
   - Visual Theme & Atmosphere
   - Color Palette & Roles
   - Typography Rules
   - Component Stylings
   - Layout Principles
   - Depth & Elevation
   - Do's and Don'ts
   - Responsive Behavior
   - Agent Prompt Guide
3. Generate or refactor UI code strictly conforming to these rules.
